# 生成PNG メタデータ比較ツール

生成したPNGを2枚並べて、設定の違いを見比べるためのツールです。
モデル、LoRA、サンプラー、ステップ数、CFG、シードなどを項目ごとに比較し、違うところに色を付けて表示します。

「前の絵と何が違うのか分からない」という時に使います。

## 使い方

1. `png_meta_compare.html` をブラウザで開く
2. 画像Aと画像Bの枠に、PNGをドラッグ＆ドロップする（クリックして選ぶこともできます）
3. 比較表が表示されます。色の付いた行が、2枚の間で違う項目です

インストールは不要です。HTMLファイルをブラウザで開くだけで動きます。

## 対応形式

- ComfyUI のPNG（埋め込みの prompt / workflow を読み取ります）
- A1111系（WebUI / Forge など）のPNG（parameters を読み取ります）
- NovelAI のPNG（Comment のJSON形式に対応。画像へ埋め込むステルス形式には未対応です）

メタデータの入っていないPNGでは、設定は表示されません。

## 特徴

- **LoRAは実際に接続されているものだけ表示**します。ComfyUIのワークフローの中で、KSamplerへ繋がっているLoRAだけを数えるので、置いてあるだけの未接続ノードに惑わされません
- **外部送信なし**。画像はブラウザの中だけで読み取ります。サーバーへ送る処理はありません
- ポジティブとネガティブのプロンプトを並べて表示し、コピーボタンでそのまま使えます
- 比較結果をテキストとしてコピーできます。検証の記録を残すのに便利です
- 追加サンプラー（ハイレゾ修正など）がある場合は、その設定も行を足して表示します

## 動作環境

モダンブラウザ（Chrome / Edge / Firefox / Safari の最近のバージョン）で動きます。オフラインでも動作します。

## ライセンスなど

- 本ツールは生成レシピの確認と比較のためのものです
